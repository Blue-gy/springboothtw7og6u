# 🏫 校园场地与设备预约管理系统

**Campus Venue & Equipment Booking System**

基于 **Vue 2 + Spring Boot** 的全栈 Web 应用，实现高校校园内场地预约、设备租赁、课程管理、活动报名、财务管理等一体化在线管理。

---

## 📋 项目概述

当前高校的场地预约（会议室、体育场馆、教室等）和设备租赁普遍依赖人工登记、微信群沟通或纸质表格。本系统旨在解决以下核心痛点：

- ❌ **效率低下**：学生需多次往返确认场地档期
- ❌ **信息不透明**：无法实时查看场地占用状态，易产生时间冲突
- ❌ **流程断裂**：从预约→审批→使用→归还→结算缺乏统一管理
- ❌ **数据缺失**：管理员无法统计分析场地使用率和财务状况

## 🛠 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | Vue 2 + Element UI + ECharts + Axios |
| 后端 | Spring Boot + MyBatis-Plus + Apache Shiro |
| 数据库 | MySQL 8.0（36 张业务表）|
| 构建 | Maven |
| 部署 | Apache Tomcat 9 |
| 设计 | PlantUML（25+ 份 UML 图表）|

---

## ✨ 核心功能

### 用户端
- 🏟️ **场地浏览与预约**：实时查看场地档期，在线提交预约申请
- 🔧 **设备租赁**：浏览可租设备，加入购物车一键租赁
- 📚 **课程预约**：查看课程信息，在线预约
- 🎉 **活动/比赛报名**：浏览活动信息，在线报名
- 👤 **个人中心**：查看我的预约、租赁、报名记录

### 管理员端
- ✅ **预约审核**：审批场地预约，支持批量操作
- 📊 **财务管理**：会员消费统计、场地租赁收入、数据可视化
- 🔒 **权限管理**：三级角色（管理员/员工/会员）+ Shiro 细粒度授权
- 📝 **系统配置**：轮播图、公告、全局参数管理
- 🔧 **维修工单**：设备/场地报修 → 派单 → 维修 → 记录全流程

## 🚀 快速启动

### 环境要求
- JDK 1.8+
- MySQL 8.0
- Maven 3.6+
- Node.js 14+

### 后端启动
```bash
# 1. 导入数据库
mysql -u root -p < db/springboothtw7og6u.sql

# 2. 修改 application.yml 中的数据库连接配置

# 3. 启动 Spring Boot
mvn spring-boot:run
```

### 前端启动
```bash
# 用户端
cd src/main/resources/front/front
npm install
npm run serve

# 管理后台
cd src/main/resources/admin/admin
npm install
npm run serve
```
