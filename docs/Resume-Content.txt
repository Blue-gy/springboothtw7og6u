【项目名称】
校园场地与设备预约管理系统
Campus Venue & Equipment Booking System

【一句话介绍】
基于 Vue + Spring Boot 的全栈 Web 应用，实现高校校园内场地预约、设备租赁、
课程活动管理等一体化在线管理。


【技术角色写法】（投后端/全栈岗）

项目经历：
校园场地与设备预约管理系统 | 全栈开发 | 2025.03 — 2025.05

• 后端使用 Spring Boot + MyBatis-Plus 构建 RESTful API，集成 Apache Shiro
  实现三级角色（管理员/员工/会员）权限控制，支持细粒度按钮级授权
• 前端采用 Vue 2 + Element UI + ECharts，实现管理后台与用户端双端分离，
  包含数据可视化图表、日历预约、设备租赁流程等功能模块
• 设计 MySQL 8.0 数据库，完成 36 张业务表建模，覆盖用户权限、预约管理、
  财务统计、维修工单等 6 大业务领域
• 编写 PlantUML 泳道图、用例图、类图等 25+ 份设计文档
• 部署环境：Spring Boot 内嵌 Tomcat + Maven 构建

【面试自我介绍（产品方向，约 1 分钟）】

我独立完成了一个校园场地与设备预约管理系统。这个项目的出发点是——
我发现学校里的场地预约和器材租借，很多时候还靠微信群里问、现场跑一趟，
效率很低，信息也不透明。

所以我从产品角度，先做了用户调研，梳理了学生、管理员、后勤主任三种角色
的核心需求，然后输出了完整的产品需求文档。功能上，我按照预约、审核、结算、
统计这条完整链路来设计，覆盖了场地管理、设备租赁、课程活动等 9 个模块。
技术落地上，我用了 Spring Boot 和 Vue 做了前后端分离的全栈开发。

这个项目让我最有收获的是——怎么从用户痛点出发去定义功能优先级，
而不是想到什么做什么。我按照 P0 到 P3 排了版本规划，
最终交付的 V1.0 解决了最核心的预约和审核流程。
