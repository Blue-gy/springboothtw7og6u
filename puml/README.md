## 在线查看方法

### 方法一：PlantUML在线编辑器（推荐）
1. 打开网址：https://www.plantuml.com/plantuml/uml/
2. 将.puml文件内容复制粘贴到左侧编辑框
3. 自动生成图表，可下载PNG/SVG格式

### 方法二：VS Code插件
1. 安装VS Code
2. 安装插件 "PlantUML"
3. 打开.puml文件，按 Alt+D 预览

### 方法三：IDEA插件
1. 安装IntelliJ IDEA
2. 安装插件 "PlantUML Integration"
3. 打开.puml文件，右侧自动预览

## 本地生成图片

需要安装Java和PlantUML：
```bash
java -jar plantuml.jar *.puml
```

## 文件编码
